# Medical Image Classification Pipeline

An end-to-end machine learning system for medical image classification.

## 🚧 Status: In Development

**Timeline**: Weeks 1-12 (May-August 2026)

## 🎯 Project Overview

This project demonstrates:
- **Data Engineering** — Apache Airflow + PostgreSQL pipelines
- **Deep Learning** — Multiple CNN architectures (ResNet, EfficientNet, Vision Transformer)
- **ML Engineering** — Production-grade FastAPI + Docker
- **Monitoring** — Model performance tracking & data drift detection
